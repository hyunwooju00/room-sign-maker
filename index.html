Common questions

Does this upload my schedule?

No. The form runs in this browser tab. It makes no schedule upload request and does not save entries to an account. If you close or refresh the tab, entries are lost.

Can I make signs for several rooms?

You can reuse this form manually for each room. For a Sessionize event with many rooms or days, Schedule Press builds the print pack from the organizer’s Schedule Grid JSON.

Will a public Sessionize timetable link work?

No. This free maker uses manual entry. The paid tool requires a Schedule Grid (GridSmart) JSON export from an organizer-created Sessionize endpoint. The free guide explains the export and print checks.
